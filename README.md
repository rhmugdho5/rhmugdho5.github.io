# Rejoan Hasan Mugdho — Personal Portfolio

A responsive personal portfolio with an editorial, minimal visual style inspired by modern developer portfolios, tailored to Rejoan's interest in cybersecurity and secure software development.

## Run locally

Open `index.html` in a browser. No build tools or package installation are required.

## Deploy to GitHub Pages

1. Extract the ZIP archive.
2. Upload all files and folders in this directory to the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your main branch and `/ (root)`, then save.

## Included

- `index.html` — portfolio content and page structure
- `reference.css` — responsive design and visual styling
- `script.js` — mobile navigation, scroll progress, reveal effects, and animated role text
- `assets/rejoan-profile.png` — portrait extracted from the supplied CV
- `assets/Rejoan_Hasan_Mugdho_CV.pdf` — supplied CV for viewing/downloading
- `assets/favicon.svg` — site icon

The site uses plain HTML, CSS, and JavaScript. Google Fonts are loaded online; system fallbacks are included. All biographical details are based on the supplied CV.
