# Rejoan Hasan Mugdho — Cybersecurity Portfolio

A responsive personal portfolio with a cybersecurity-focused visual identity. Built with plain HTML, CSS, and vanilla JavaScript so it can be hosted directly on GitHub Pages without a build step or package installation.

## Preview locally

Open `index.html` in a browser, or start a local server in this folder:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

## Deploy on GitHub Pages

1. Extract the ZIP archive.
2. Upload all files and folders (including the `assets` folder) to the root of your GitHub repository.
3. Commit and push the changes to your default branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose your default branch and `/ (root)`, then save.

## Included assets

- `assets/rejoan-profile.png` — portrait extracted from the supplied CV.
- `assets/Rejoan_Hasan_Mugdho_CV.pdf` — original CV, linked from the site.
- `assets/favicon.svg` — custom shield-style favicon.

## Customize

- `index.html` — text, profile links, sections, and project details.
- `styles.css` — colors, typography, layout, responsive behavior, and animation.
- `script.js` — mobile navigation, scroll progress, reveal effects, and the rotating hero role text.

## Content accuracy

The site presents cybersecurity as a career direction and learning focus, not as professional experience or a completed security specialization. Project, education, course, recognition, and contact details are based on the supplied CV. No security certifications, penetration-testing experience, or unlisted projects have been added.

The page uses Google Fonts when available, with local system-font fallbacks. No JavaScript libraries or build tools are required.
